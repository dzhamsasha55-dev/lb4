# Лабораторна робота № 4. Цикли

Алгоритмізація та програмування.

Джамалов Олександр Олегович, РІ-11. Варіант 7.

У reports містяться сім звітів DOCX. У src містяться сім окремих програм C++17.
Кожна програма компілюється незалежно від інших.

Приклад компіляції:
g++ -std=c++17 -O2 src/Lab_04_1.cpp -o lab041
Запуск у Linux або macOS: ./lab041
Для решти завдань замініть ім'я вихідного файлу.

Ввід: 4.1 - N; 4.2 - xp xk dx; 4.3 - a b c, потім xp xk dx;
4.4 - R, потім xp xk dx; 4.5 - R і десять пар x y;
4.6 - без вводу; 4.7 - xp xk dx, потім eps.
Можна задавати зростаючу або спадну сітку, погодивши знак dx.
Максимальна кількість кроків табуляції: 100000.
У 4.4 необхідно 0 < R < 6. У 4.7 необхідно -1 <= x <= 1 та eps > 0.
У 4.7 після 10000000 доданків без досягнення точності виводиться no convergence.
Фіксоване зерно 7 у 4.5 робить псевдовипадкові точки відтворюваними.
